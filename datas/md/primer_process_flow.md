# 半导体制造主流程（简化）

集成电路制造通常在洁净室中对硅晶圆反复进行成百上千步工艺。可粗分为：

1. **前端（FEOL）**：在硅中形成晶体管等有源器件（氧化、注入、栅极、隔离等）。  
2. **中段（MEOL）**：接触、局部互连等，连接器件到布线。  
3. **后端（BEOL）**：多层金属互连、介质、过孔，完成电路连线。  
4. **后道封装测试**：切割、封装、测试（部分在晶圆厂外完成）。

## 四大「积木」工艺如何配合？

| 工艺 | 角色 |
|------|------|
| **光刻** | 定义这一层要做什么图形 |
| **刻蚀** | 按图形去掉材料，形成结构 |
| **沉积（CVD/PVD/ALD）** | 长上或镀上需要的薄膜 |
| **CMP** | 磨平表面，保证下一层光刻可行 |

典型循环（示意）：沉积 → 光刻 → 刻蚀 →（清洗）→ 再沉积 → CMP → 下一层光刻……

## 为什么知识库要覆盖这些基础定义？

企业问答中大量问题是「什么是 CMP / EUV / 等离子体刻蚀」。若语料只有论文细节而缺少入门定义，检索容易偏题或被迫联网。基础工艺百科用于补齐这类**概念空洞**。

## 常见问题（FAQ）

**Q：光刻之后通常做什么？**  
A：常见是显影后进行刻蚀或离子注入，再去胶、清洗。

**Q：CMP 一般出现在流程的哪里？**  
A：多出现在沉积与图形化之后，为下一层光刻提供平坦表面，尤其在 BEOL 金属互连中频繁使用。
