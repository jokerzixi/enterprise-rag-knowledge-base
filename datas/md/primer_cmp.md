# CMP（化学机械抛光）是什么？

**CMP**（Chemical Mechanical Polishing / Planarization，化学机械抛光或化学机械平坦化）是半导体制造中用于**平坦化晶圆表面**的关键工艺。它把化学腐蚀与机械研磨结合起来：化学液软化或溶解表面材料，抛光垫与磨料颗粒提供机械去除，从而使晶圆达到后续光刻、沉积等工序所需的平整度。

## 为什么需要 CMP？

多层互连与多层薄膜沉积后，晶圆表面会出现台阶、凸起和凹陷。表面不平整会导致：

- 光刻焦深不足、图形失真
- 后续薄膜厚度不均匀
- 金属连线短路或断路风险升高

CMP 的目标是在全局或局部尺度上把表面「磨平」，保证工艺窗口。

## CMP 基本组成

1. **抛光液（Slurry）**：含化学试剂与磨料颗粒，决定去除速率与选择性。
2. **抛光垫（Pad）**：与晶圆接触，传递机械力。
3. **抛光头 / 载具**：固定晶圆并施加压力与旋转。
4. **终点检测**：通过光学、电机电流、摩擦等信号判断何时停止，避免过度抛光。

## 常见应用场景

- **浅槽隔离（STI）** 后的介质平坦化
- **金属互连**（如铜 Dual Damascene）中的铜与阻挡层抛光
- **层间介质（ILD）** 平坦化
- 先进封装与某些 MEMS 结构的表面处理

## 与相近概念的区别

| 概念 | 说明 |
|------|------|
| 机械抛光 | 主要靠物理研磨，化学作用弱 |
| 化学腐蚀 | 主要靠湿法化学去除，形貌控制弱 |
| **CMP** | 化学 + 机械协同，兼顾速率、选择性与平坦度 |

## 常见问题（FAQ）

**Q：CMP 的中文全称是什么？**  
A：化学机械抛光，也常称化学机械平坦化。

**Q：CMP 在半导体制造中主要做什么？**  
A：平坦化晶圆表面，为后续光刻与多层布线提供平整基底。

**Q：过度 CMP 会有什么问题？**  
A：可能造成碟形凹陷（dishing）、侵蚀（erosion）、划伤或薄膜被磨穿，影响良率。
