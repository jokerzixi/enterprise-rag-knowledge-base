# 量测（Metrology）是做什么的？

**量测**用光学、电子束等手段测量关键尺寸、膜厚、套刻误差与缺陷，判断工艺是否落在规格内，并为反馈控制提供数据。

## 几个高频指标

| 指标 | 含义 |
|------|------|
| **CD（Critical Dimension）** | 关键线宽/关键尺寸 |
| **Overlay（套刻）** | 当前层相对前层的对准误差 |
| **膜厚** | 沉积或氧化后的厚度与均匀性 |
| **缺陷检测** | 颗粒、图案异常等 |

## 为何套刻很重要

多层互连与多重曝光对层间对准极敏感。套刻超差会导致接触不良、短路或性能漂移，是先进节点良率杀手之一。

## 常见问题（FAQ）

**Q：量测会改变晶圆吗？**  
A：多数在线量测为非破坏或微损；部分失效分析（如切片 TEM）是破坏性的。

**Q：CD-SEM 是什么？**  
A：用扫描电镜测量关键尺寸的常用手段，分辨率高，适合精细图形。
